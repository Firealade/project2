# 🎓 Öğrenci Not Ortalaması Hesaplayıcı

Bu proje, Java kullanılarak geliştirilmiş konsol tabanlı bir dönem sonu not hesaplama uygulamasıdır.

## 🚀 Özellikler
* Kullanıcıdan **Vize** (%40) ve **Final** (%60) notlarını alır.
* Ağırlıklı ortalamayı otomatik hesaplar.
* Geçme/Kalma durumunu (Baraj: 50) ekrana yazdırır.

## 💻 Nasıl Çalıştırılır?
Projeyi bilgisayarınızda derlemek ve çalıştırmak için terminalde şu komutları kullanabilirsiniz:

```bash
javac Main.java
java Main
